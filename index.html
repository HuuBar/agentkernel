快速开始 

# 安装
pip install git+https://github.com/HuuBar/agentkernel.git

# SDK 模式
from agentkernel import BACGRuntime

runtime = BACGRuntime(budget={"tokens": 5000, "usd": 5.0})
result = await runtime.llm_call(prompt, model="gpt-4")

# 检查状态
print(runtime.remaining)  # 剩余预算
print(runtime.branching_stats)  # 拓扑统计

六层约束面 

Layer 6: 拓扑 (Topology)     → 全局: max_depth, branching factor
Layer 5: 并发 (Concurrency)  → 层级: max parallel nodes per level
Layer 4: 质量 (Quality)      → 路径: quality decay along path
Layer 3: 安全 (Security)     → 边级: allowed child operations
Layer 2: 资源 (Resource)     → 路径: cumulative budget token flow
Layer 1: 身份 (Identity)     → 节点: actor permission check

三层嵌入 

Layer 3: Gateway  (零侵入)     → 网络代理, 改环境变量即可
Layer 2: Adapter  (框架集成)   → LangGraph / AutoGen / OpenAI SDK
Layer 1: SDK      (深度集成)   → 直接调用 runtime.llm_call()
