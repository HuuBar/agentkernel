Core Modules

topology/token.py — BudgetToken

多维资源令牌，借鉴 Petri 网 token 流动和 CHERI 能力单调性。split() 保证总量只减不增。

topology/constraints.py — 6 Constraint Layers

Photoshop 图层风格的6层约束面：Identity、Resource、Security、Quality、Concurrency、Topology。

topology/graph.py — CallGraph

属性有向树容器，支持5种图变换：Survey、Calibrate、Expand、Contract、Rebalance。

topology/agent.py — BACGAgent

拓扑感知 Agent，执行循环：Survey → Calibrate → Exploit。分支过程模型预测资源消耗。

topology/integration.py — BACGRuntime

统一资源控制运行时，支持 SDK/上下文管理器/装饰器三种模式，内置 OpenAI/LangGraph/AutoGen 适配器。

topology/branching.py — BranchingModel

Galton-Watson 分支过程模型：E[Total] = E[C] / (1 - m)。m >= 1 时强制终止。

Quick Start

from agentkernel import create_bacg

# Create a BACG runtime with 2000 token budget
runtime = create_bacg(budget={"tokens": 2000}, framework="sdk")

# Check if operation is allowed
can_do, reason = runtime.can_execute("llm_call", {"tokens": 500})
if can_do:
    print("Operation allowed!")
else:
    print(f"Blocked: {reason}")

# Use context manager
async with runtime.monitor("search", {"tokens": 200}) as op:
    results = await search_api.execute(query)
    op.record_actual(results.usage)

Mathematical Foundation

Galton-Watson 分支过程：

E[Total] = E[C] / (1 - m) 当 m < 1 时收敛

其中：
m = E[Z] = 平均分支因子
E[C] = 每次调用的平均消耗

如果 m ≥ 1，期望总消耗无穷大 → 必须强制终止。
